# Tidy Components documentation site

Upload these two files to a public GitHub repository (for example `tidy-components`) and turn on
**Settings › Pages › Deploy from a branch › main / (root)**. The guide is then live at
`https://<your-username>.github.io/tidy-components/`. Use that address as the plugin's DocsURL
(`-DocsUrl` in `BuildScripts/Package-ForFab.ps1`) and as the documentation link on Fab.

Upload only these files, never the plugin source.
